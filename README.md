# Lanes

Arcade cook demo: run a recipe through timed Guitar Hero lanes.

## Play

```bash
npm install
npm run dev
```

Open `/` — hit **Start Cook**, then strike notes on Board / Pot / Finish as they reach the line.

- Keys: `A` Board · `S` Pot · `D` Finish · `Space` nearest note
- Tap lanes on tablet (landscape works best)
- Sound is muted by default (`MUTE` / `SND` in the HUD)

## Demo recipe

Hardcoded **weeknight lentil curry** (~2.5 min of play): dice, bloom, simmer, coconut, plate.

## Stack

Next.js App Router · TypeScript · Tailwind · ready for Vercel (`npm run build`).
